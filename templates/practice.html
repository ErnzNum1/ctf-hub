Practice Labs

Want more? These are free, open-source apps that are built to be hacked. You run them on your own computer, so nobody gets hurt and nothing is illegal.

Rule #1: only test systems you own or that clearly allow it. Never scan or attack a real website without written permission.

OWASP Juice Shop

A modern online shop full of security bugs, with a built-in score board. Great for beginners who want to try many web vulnerabilities.

Official page

DVWA

"Damn Vulnerable Web Application". A classic PHP and MySQL app with levels (low, medium, high) for SQL injection, XSS and more.

Project page

WebGoat

A guided lesson app from OWASP that teaches you how web bugs work step by step.

Project page

How to run one on your computer (example: Juice Shop)

  1. Install Docker Desktop from docker.com and open it.
  2. Open a terminal and run: 
    docker run --rm -p 3000:3000 bkimminich/juice-shop
  3. Open http://localhost:3000 in your browser.
  4. Press Ctrl + C in the terminal when you are finished.

Each project has its own install guide on its official page. Please follow that guide, since steps can change over time.
